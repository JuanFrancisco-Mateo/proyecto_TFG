# CENTRO DE BUCEO
Aplicación de escritorio desarrollada en JavaFX para la gestión de reservas, clientes, instructores y usuarios de un centro de buceo.
## Tecnologías utilizadas
- Java 21
- JavaFX
- Scene Builder
- MariaDB
- Maven
- BCrypt
## Requisitos previos
Antes de ejecutar la aplicación es necesario tener:
- Java 21
- Maven
- MariaDB
- Un servidor MariaDB funcionando en el puerto 3306
## Instalación de la base de datos
- Crear una base de datos llamada centro_buceo
