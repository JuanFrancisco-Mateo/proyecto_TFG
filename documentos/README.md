# Documentación del proyecto
Esta carpeta contiene la documetnación técnica elaborada durante el desarrollo del Proyecto Intermodular.
El proyecto consiste en el desarrollo de una aplicación para la gestión y reserva de actividades de buceo, cuyo objetivo es facilitar la gestión de las reservas y sustituir el proceso manual que actualmente se realiza mediante hojas de cálculo.
## Contenido de la documentación
### 01. Análisis del sector.
Estudio del sector de las actividades de buceo, incluyendo las necesidades detectadas y la oportunidad de aplicar una solución tecnológica para mejorar la gestión de las reservas.
### 02. Análisis y planificación del proyecto.
Análisis de los requisitos y necesidades del proyecto, junto con la planificación de las diferentes fases y tareas necesarias para desarrollar la aplicación.
### 03. Acta de constitución.
Documento inicial del proyecto en el que se definen los objetivos, alcance y otros aspectos relevantes para su puesta en marcha.
### 04. Casos de uso.
Descripción de las principales funcionalidades de la aplicación y de las interacciones que pueden realizar los usuarios.
### 05. Diseño de la base de datos.
Documentación correspondiente al diseño y estructura de la base de datos utilizada.
### 06. UML.
Diagramas UML utilizados para representar diferentes aspectos del funcionamiento y estructura de la aplicación.
### 07. Wireframes.
Diseños y prototipos de las diferentes pantallas y vistas de la aplicación.
### 08. Instalación y puesta en marcha.
Instrucciones necesarias para la configuración y uso de la aplicación.
### 09. Seguimiento del proyecto.
Documentación relacionada con el seguimiento y evolución del proyecto durante su desarrollo.
